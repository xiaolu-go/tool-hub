# 功能变更记录

每次修改与代码同次提交，记录用户可见变化、计算口径及实际验证。日期使用本地日期。

## 2026-11-08：新增图片处理与文字水印

- 根据用户新增需求加入图片工具；统一注册首页、导航和按需加载路由，首页本地数据说明同步修正。
- 支持单张 PNG／JPEG／WebP 的像素裁剪、比例缩放、旋转、翻转、格式转换、质量调整与 JPEG 背景色。
- 支持内置与自定义文字水印，四角／居中／平铺，字号、颜色、不透明度；主动保存与删除最多 10 条常用文案。
- 图片和草稿仅在浏览器内存，常用文案单独保存于浏览器。实时预览与下载共用同一编码文件；限制尺寸与像素，非法参数禁用下载，加载编码失败保留原编辑并处理异步竞态和 URL 回收。
- 新增 19 项真实边界域测试与 10 项桌面／手机图片浏览器测试，包括实际下载图片像素、编码格式、透明区域、水印效果和失败保护。修正嵌套标签混入说明文字、重新锁定比例时高度未即时恢复，以及选择自定义文案时输入框未清空聚焦的问题。
- 最终验证：类型检查通过、7 文件 132 项单元测试通过、生产构建通过、16 项桌面／手机浏览器测试全部通过（58.0 秒，含养老金回归 6 项）、`git diff --check` 通过；已查看桌面及手机水印页面截图。原生选择窗口由自动化上传替代，截图与生成样图未提交。
- 同步需求 1.4、README、实施计划与 D014 决策；养老金金额模型与计算规则保持版本 3。

## 2026-11-04：独立方案列表与文件夹测算记录

- 原共用计划改为逐行独立方案，新增银行／保险下拉、开始存入及领取至列；默认年龄、两个全空行，支持添加和移除录入行。
- 银行从存入第一年计息；保险在存入期间不计息，最后存入的下一年起对全部本金复利。更新为模型 3，添加手算对照和负利率、舍入、年龄上限测试。
- 按用户后续修正，新记录改存所选文件夹的 `tool-hub-pension-records.json`。支持搜索、类型筛选、查看、编辑重算、确认删除、重新读取和显式导入旧版设置。
- 全部非空行通过校验且写文件成功后，显示结果并清空成两个空行；缺项、保存失败、外部文件修改时保留表单。旧版导入保留旧起息规则，编辑后使用新规则。
- 汇总、图表、年度明细和 CSV 按独立方案生成；各方案可以有不同时间范围。修复窄屏表格隐藏标签越界导致的页面溢出与按钮点击偏移。
- 更新 README、AGENTS、规格、计算规则、实施状态及决策；旧规格和旧计算规则归档。个人记录文件加入忽略规则。
- 实现提交 `5be9e52`，已连同基线 `788df23` 推送 GitHub origin/main；此后的修改继续按 AGENTS 要求同步代码与文档。
- 最终验证：113 项测试、6 项桌面／手机浏览器测试、类型检查与构建全部通过；细节见 `implementation-plan.md`。目录选择器使用替身连接实际文件，不把此结果当作原生权限窗口的手工验证。
