# 第一期需求、页面与验收标准

版本：1.3；更新：2026-11-04。本文替代 v1.2；旧版见 `archive/phase-1-spec-v1.2.md`。

## 目标与范围

项目名称保持 tool-hub。提供网页工具首页及养老金资金计算器，中文界面。收支规划仍只展示规划中入口。无后台、账户、真实产品数据、按月现金流或桌面版。

本次变更：由“共用计划 + 两个收益率”改为“每行独立方案”；由浏览器保存改为用户选择文件夹保存；银行与保险区分起息时间。优先级高于旧版文档相关约定。

## 工具集与页面

首页卡片展示名称、说明和标签，进入计算器；统一导航、返回首页及 404 保留。计算器顺序为文件夹选择、方案录入列表、状态提示、本次或查看的结果、测算记录、折叠规则。

### 方案录入

默认按年龄、两个完全空白的行，类型不预填。每行一套独立现金流参数；同批次采用统一年龄或年份模式。可以添加及移除录入行，至少保留一行；序号由显示顺序生成，不作为记录编号。

| 表头 | 内容与校验 |
| --- | --- |
| 序号 | 自动生成 |
| 类型 | 下拉必选银行或保险 |
| 方案名称 | 去除首尾空格后 1–30 个字符 |
| 开始存入（年龄／年份） | 年龄 0–104；年份 1900–2200，整数 |
| 年存入额（元） | 大于 0、不超过 10 亿元，最多两位小数 |
| 存入年数 | 1–100 的整数 |
| 年化率（%） | −100 至 100，最多四位小数；0 必须手动填写 |
| 开始领取（年龄／年份） | 年龄 1–105；年份 1901–2319；晚于最后存入周期 |
| 年领取额（元） | 与年存入额同样的金额限制 |
| 领取至（年龄／年份） | 必填，包含结束当年；不早于开始领取；年龄最高 105 岁，年份最多测算 120 个周期 |
| 操作 | 移除当前录入行 |

年龄指整岁年度周期，无生日或日历换算。切换模式保留名称、类型和金额等字段，清空三个时间字段，避免把 40 岁误当作公历 40 年。编辑历史记录时自动选择该记录的时间模式。

本版通过明确的“领取至”保留结束条件，取代旧版指定领取年数／领至耗尽开关；资金提前耗尽仍显示至结束周期，用于识别缺口。

### 提交与错误

- 整行全空可以跳过；任一字段填过（含类型）即要求该行完整。
- 所有非空行都通过校验才可保存；有错误时标注行、单元格和文字说明，聚焦第一个错误，不保存其中的部分正确行。
- 两行均空时提示至少填写一个方案。
- 未选择文件夹时提示选择文件夹并保留输入。
- 计算和文件写入成功后才展示本次结果，清空录入，恢复两个空行。
- 文件读取、权限、写入、冲突失败时保留输入和已有文件，不创建虚假的成功状态。
- 保存期间锁定重复操作。修改录入不会改变已保存的结果快照；新录入与已保存的结果是独立对象。

### 文件夹与记录

用户通过“选择记录文件夹”指定位置。固定文件名 `tool-hub-pension-records.json`，UTF-8，包含格式版本、文件修订标识、每条记录的独立编号、创建／更新时间、规则版本、参数与年度结果。保存前读取当前文件并与原始文本比较；检测到外部修改则阻止覆盖并提示重新读取。

新记录、文件夹句柄和未提交表单均不写浏览器存储；页面刷新后默认两个空行，需重新选择文件夹。选择成功自动读取已有文件；无文件则从空记录开始。未知格式、未知规则版本、重复编号或无效输入拒绝整体载入，避免用部分数据覆盖原文件。首次写入失败留下的空文件允许重试。

增：测算成功按行生成记录。查：名称搜索、类型筛选、查看汇总与年度明细。改：回填单条记录，重新测算并更新原编号，保留创建时间，更新修改时间。删：确认后从文件移除；取消／Escape 不改文件；删除失败在弹窗中说明。操作只作用于当前所选文件的记录，不移除其他文件。

刷新后通过重新选择文件夹读取，不自动还原输入。支持“重新读取”检查外部文件变化，保留正在录入的内容。导入旧版测算为显式操作：读取旧浏览器中的最后成功方案并写入当前文件夹，不再写入浏览器；类型默认按旧 A／B 对应银行／保险，标明“旧版规则”。导入采用旧共同时间轴的实际结束位置作为固定结束条件；编辑重算转为当前规则。

直接选择文件夹依赖浏览器 File System Access API，运行在 HTTPS 或 localhost 安全上下文。建议电脑 Edge／Chrome；不支持时明确提示，不回退到浏览器持久化。不把手机模拟测试等同于手机原生文件夹支持。

### 结果与导出

同批方案显示独立汇总（类型、时间范围、累计存入、收益、领取、余额、足额年数、首次不足额）。用方案选择器查看单条余额与领取图表、年度明细。不同方案的起止位置与领取条件可以不同，不默认同轴差额比较。历史查看消费已保存快照；重新打开文件时按其规则版本校验和重建结果。

CSV 导出当前展示的方案，包含记录编号、类型、时间模式、年龄／年份、阶段、全部年度金额、独立参数、起息位置、规则版本及更新时间。名称防公式注入。图表失败时表格仍可用。

### 布局与可访问性

列表有表头，输入关联行号及字段名称，类型用原生下拉。窄屏仅表格横向滚动，页面整体不溢出。键盘可以访问表格与控件，错误文字关联对应字段。手机输入字号避免自动放大；表格内隐藏标签定位于单元格，避免越界撑开视口。
