## 本次实际验证

Windows 10、Node.js 24.22.1、npm 11.19.1，本机 Edge 无头执行浏览器测试，验证生产构建。

| `npm test` | 6 个文件、113 项全部通过，约 12 秒 |
| `npm run build` | 通过 |
| `npm run test:browser` | 1440×1000 桌面与 375×812 手机，共 6 项通过 |
| `git diff --check` | 通过 |
| 生产预览 | 本地 4173 服务提供最新 dist，刷新后选择文件夹使用 |

覆盖独立银行与保险正负利率、存入结束后起息、年末领取、半分舍入、105 岁上限、年龄／年份等距、无等待期、耗尽及不足额、导出防公式注入。新增文件用例覆盖往返保存、增改删、外部修订、手动改文件未改版本号、损坏／未知版本、重复编号、失败后原文件保持、首次中断空文件可重试、规则版本重建。

界面与浏览器流程覆盖：默认年龄与两空行，整行空白跳过、部分行拒绝整批保存、字段错误定位、无目录与写失败保留输入；成功写入后清空并将横向表格滚回起点；名称搜索、类型筛选、查看结果、编辑保留编号与创建时间、取消及确认删除；CSV 实际下载、图表 SVG 渲染、刷新后选择目录读取、localStorage 未新增记录、首页和 404。

目录选择器在自动化中由受控替身返回，读写连接测试输出目录里的实际 JSON 文件；不弹出原生系统选择目录窗口。这验证了应用文件协议和操作逻辑，尚不等于实际用户目录权限窗口的手动验证。手机项目验证窄屏布局与交互，真实目录选择建议电脑 Edge／Chrome。测试数据和截图位于忽略的 `test-results/`，不入版本库。

已人工查看桌面和手机的列表、结果、图表与记录截图。修复了表格中绝对定位隐藏标签跨出滚动区域导致的视口膨胀和点击偏移；现在页面整体不横向溢出。改为单元格定位，并在测试中用 documentElement.clientWidth 检查溢出。
