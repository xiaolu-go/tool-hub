# tool-hub

网页版个人工具集，第一期提供养老金资金计算器：在同一份年度存入和领取计划下，对比两种假设收益率，查看累计领取、期末余额、资金耗尽情况及逐年明细。

## 运行

使用 Node.js 22.12 或更高版本（推荐 Node.js 24）。依赖的实际版本由 `package-lock.json` 固定。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址；默认端口为 5173，端口占用时以终端输出为准。无需环境变量、登录、后端或数据库。

```sh
npm run check       # TypeScript 类型检查
npm test            # 计算、校验、保存、导出和关键交互测试
npm run build       # 类型检查与生产构建，产物在 dist/
npm run preview     # 本地预览生产构建
npm run test:browser # 构建后验证桌面和手机的真实浏览器流程
```

浏览器验证优先使用 Windows 上已有的 Edge 或 Chrome。其他环境先运行 `npx playwright install chromium`；也可通过 `TOOL_HUB_BROWSER_PATH` 环境变量指定浏览器程序。测试预览端口为 4174，测试结果和截图保存在忽略版本管理的 `test-results/`。

开发及验证环境：Node.js 24.22.1、npm 11.19.1。当前锁定 React 19.3.1、Vite 8.3.5、TypeScript 7.0.2、Vitest 5.1.0、ECharts 6.1.0、decimal.js 10.6.0；其他依赖详见锁文件。

## 功能

- 卡片式工具首页、统一导航与未找到页面。
- 一组共用计划、两行方案设置，方案仅分别填写名称与利率。
- 每年固定金额存入、自定义开始领取年份和每年领取金额。
- 支持按年龄：几岁开始存、存几年、几岁开始领、领到几岁，最高 105 岁，包含结束年龄当年。
- 指定领取年数、领至耗尽两种模式，最多测算 120 个自然年。
- 两个方案共用现金流计划，分别设置名称和假设年收益率。
- 阶段时间线、双方案汇总、余额曲线、领取对比和完整年度明细。
- 最近成功参数保存在当前浏览器；刷新后重新计算恢复结果。
- 导出带中文表头、公共参数和两方案年度明细的 CSV。
- 电脑与手机布局；键盘操作、字段错误说明和恢复默认确认。

## 计算口径

按年龄以整岁为一个年度周期，不依赖生日或自然年换算；例如 60 岁领至 85 岁，共领取 26 年。旧年份模式的保存设置可以兼容恢复。

初始余额为 0，年初存入，存入后计算当年收益，年末领取。收益率全程固定，年度收益按分舍入，正负半分均远离 0 舍入。余额不足时领取剩余金额，不透支。

所有金额使用 decimal.js 十进制计算，结果按年度累计。金额输出为十进制文本，表格、图表与导出共用同一结果快照。参数编辑后必须重新测算才能导出。

本期的“银行假设方案”“保险假设方案”是可修改的假设名称，默认 2% 和 3% 是演示参数，不代表实际或保证收益。账户余额不等同于具体保险合同现金价值；模型未计通胀、税费、手续费、终身年金及保证利益。达到上限未耗尽，不代表无限领取。

## 数据与部署

参数使用当前站点的 localStorage 保存，不会主动上传。清理浏览器数据、切换浏览器、切换域名或端口后，原保存设置可能不可用。存储不可用时仍能测算和导出。

将 `dist/` 内容部署到静态托管即可。使用相对资源路径与 Hash 路由，计算器地址形如 `/#/tools/pension-calculator`；业务路由不依赖服务端重写。不支持直接双击 `dist/index.html` 运行，应通过 HTTP 预览或静态托管访问。
