# tool-hub

网页版个人工具集，提供养老金资金计算器和图片处理。养老金每行一个独立方案，记录保存到用户选择的文件夹；图片在浏览器本地编辑、加水印与下载。

## 运行与验证

使用 Node.js 22.12 或以上版本，推荐 Node.js 24；依赖版本由 `package-lock.json` 固定。

```sh
npm ci
npm run dev
npm run check
npm test
npm run build
npm run preview
npm run test:browser
```

开发服务默认 5173，生产预览 4173；以终端实际地址为准。无需环境变量、账号、后台或数据库。

浏览器测试在 4174 运行。Windows 优先使用已安装的 Edge／Chrome；其他环境使用 `npx playwright install chromium`，或通过 `TOOL_HUB_BROWSER_PATH` 指定浏览器。自动化测试用选择器替身连接临时真实 JSON 文件，验证应用文件读写、记录增删改查和失败保护；原生系统选文件夹的对话框仍由用户手动操作。手机视口测试验证布局，不代表手机浏览器支持原生文件夹 API。

## 使用

1. 打开计算器，点击“选择记录文件夹”。推荐使用电脑上的 Edge 或 Chrome，通过 localhost 或 HTTPS 访问。浏览器会请求所选文件夹的读写权限；不支持此能力时页面会明确提示。
2. 默认按年龄，两个空行。选择银行／保险，填写方案名称、开始存入、年存入额、存入年数、年化率、开始领取、年领取额和领取至。可添加行；窄屏可横向滚动表格。
3. 点击“测算并保存”。整行空白跳过，部分填写则提示补全。文件写入成功后展示结果并清空为两个空行；失败保留录入。
4. 在测算记录中搜索、按类型筛选、查看、编辑重算或删除。编辑更新原记录；删除需确认。
5. 刷新后重新选择同一文件夹读取记录。记录文件为 `tool-hub-pension-records.json`，备份或换设备时复制该文件即可。

新记录与目录句柄均不保存在浏览器。旧版本最后成功设置可用“导入旧版测算”显式迁入文件，旧记录标明原始计息规则；编辑后应用当前规则。数据文件与 CSV 不要提交到项目仓库。

## 图片处理

从首页或导航进入“图片处理”，选择或拖入一张 PNG、JPEG、WebP。支持像素裁剪、锁定比例缩放、90° 旋转、水平／垂直翻转和重置；可导出 PNG、JPEG 或 WebP，JPEG／WebP 支持质量调整，JPEG 支持透明区域背景色。

启用文字水印后，可以选择内置文案或输入自定义内容，调整四角／居中／全图平铺位置、字号、颜色和不透明度。点击“保存为常用文案”可保存最多 10 条文案到当前浏览器，也可删除。图片、草稿与结果均不上传、不持久化；刷新后重新选图。

图片最大 25 MB，原图与输出均限每边 8192 像素、总计 1600 万像素。暂不支持批量或保留动图。图片实时编码预览，下载与预览共用同一文件；输入无效或生成中不能下载旧结果。浏览器决定下载位置，原文件不修改；重新编码不保留 EXIF 等元数据。参数与业务边界见需求文档。

## 计算

银行从首笔存入当年起按年复利；保险在整个存入期间不计息，最后存入的下一年开始对全部本金按年复利。每年年初存入，计息后于年末领取。利率为固定假设，金额使用十进制，年度收益按分舍入。

默认按年龄，最高 105 岁，包含结束当年；例如 60 岁至 85 岁领取 26 年。也可按公历年份输入，最多测算 120 年。余额不足只领剩余资金，继续记录至结束条件的缺口，不透支。

每条方案有独立汇总、余额／领取图表、年度明细，CSV 按同一快照导出。银行与保险只是用户要求的起息模型，不代表真实合同利益；不含通胀、税费、手续费或保证收益。
